## Recent updates to watch

Short, practical pointers from official GitHub sources (as of 2026-10-04).

### Copilot

- Copilot code review now has API support and a new default effort level. Source: [GitHub Changelog, 2026-10-02](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level)
- Some models in GitHub Copilot were deprecated, so check your model picker. Source: [GitHub Changelog, 2026-10-02](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated)
- Copilot can now interact with desktop apps. Source: [GitHub Changelog, 2026-10-01](https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps)
- Beginner guide: [GitHub Copilot app for Beginners: How to build custom workflows with canvases](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-build-custom-workflows-with-canvases/). Source: GitHub Blog.

### GitHub Actions and automation

- The macOS 14 runner image is being retired; move workflows to a newer macOS label. Source: [GitHub Changelog, 2026-10-01](https://github.blog/changelog/2026-10-01-github-actions-macos-14-runner-image-retirement)
- Stateless GitHub App installation tokens have rolled out. Source: [GitHub Changelog, 2026-10-02](https://github.blog/changelog/2026-10-02-stateless-github-app-installation-tokens-rolled-out)
- Agentic workflow examples (daily issues report, stale repo checks, release compliance) are listed in the [Awesome Copilot workflows collection](https://github.com/github/awesome-copilot/tree/main/workflows). Source: Awesome Copilot.

### Collaboration and security

- Private vulnerability reports gained structured forms and rate limits. Sources: [structured forms](https://github.blog/changelog/2026-10-01-structured-forms-for-private-vulnerability-reports), [rate limits](https://github.blog/changelog/2026-10-01-rate-limits-for-private-vulnerability-reports) (GitHub Changelog, 2026-10-01)
- Repository security advisories support confidential comments. Source: [GitHub Changelog, 2026-10-02](https://github.blog/changelog/2026-10-02-confidential-comments-on-repository-security-advisories)
- Read [Highlights from Git 2.56](https://github.blog/open-source/git/highlights-from-git-2-56/) for new Git features. Source: GitHub Blog.
